# crito-api

Общая headless-CMS для корпоративных сайтов, которые собираются из готовых блоков. Редактор правит контент и собирает страницы в админке без релиза. Разработчик добавляет новые блоки и макеты в коде.

Первый подключённый проект — **RuCode**. Архитектура рассчитана на несколько проектов с общими блоками и собственными темами.

---

## Основные понятия

| Понятие | Что это |
|---|---|
| **Проект** | Отдельный сайт со своим набором страниц, манифестом блоков, ключами шапки/футера и темой |
| **Страница** | Slug, SEO, ключи шапки и футера |
| **Блок** | Экземпляр компонента на странице |
| **Манифест** | Список типов блоков проекта с их схемами. Публикуется из CI при деплое фронтенда |
| **Схема блока** | Описание данных блока (zod на фронтенде → JSON Schema на бэкенде). Есть схема — блок редактируемый |

## Возможности

### Для редактора
- Правка содержимого блоков, у которых описана схема.
- Включение, скрытие и перестановка любых блоков.
- Якоря для ссылок вида `/#anchor`.
- SEO страницы: title, description, og-заголовок, og-описание, og-картинка.
- Создание новых страниц из каталога блоков: slug, ключ шапки и футера из разрешённого набора, SEO.
- Публикация сразу после сохранения: версия повышается, кэш сайта сбрасывается вебхуком (без вебхука — через 60 секунд).

### Для сайта
- Страницы берутся из CMS. При ошибке (404, 502, таймаут, невалидный ответ) используются локальные данные из `*.data.ts`.
- Страницы без записи в CMS продолжают работать на локальных данных, поэтому подключать их можно по одной.
- Страницы, созданные в админке, открываются по своему slug; несуществующие отдают 404.
- Rich-text очищается повторно на стороне сайта, секрет вебхука проверяется, токены не попадают в браузер.

### Для разработчика
- Каталог блоков и формы админки строятся из манифеста. Под новый блок бэкенд и админку дорабатывать не нужно.
- Бэкенд валидирует данные блоков по JSON Schema и не публикует страницы с неизвестным `type`.
- Чтобы сделать блок редактируемым, достаточно описать его схему.

## Стек

- **Фронтенд:** Nuxt, Vue, Tailwind CSS, zod
- **Бэкенд:** Nest.js, Prisma
- **БД:** PostgreSQL
